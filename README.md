# Forja

An engine for building fully dynamic, reusable forms.

## Goal

Configure a complete form (fields, sections, validations and conditional logic)
**without changing a single line of code**.

Form definitions are data, not code: they are versioned and published, and
every submission stays tied to the exact version of the form it was filled in
with.

The first use case is taking reports of crimes, where the kinds of report and
the information each one needs are not settled yet. The engine itself is
generic and can serve any other process.

## En español

Forja es un motor para crear formularios completamente dinámicos y
reutilizables: campos, secciones, validaciones y lógica condicional se
configuran sin modificar código. El primer caso de uso es la toma de
denuncias.
